Glossary: threat data and standards

CVE

Common Vulnerabilities and Exposures, the public ID each known flaw gets

CWE

Common Weakness Enumeration, the root-cause category of a flaw

CPE

Common Platform Enumeration, standard product names

NVD

National Vulnerability Database (USA)

CISA

Cybersecurity and Infrastructure Security Agency (USA)

KEV

Known Exploited Vulnerabilities, CISA’s list of flaws used in real attacks

EPSS

Exploit Prediction Scoring System, the odds a flaw is attacked in 30 days

CVSS

Common Vulnerability Scoring System, the 0–10 severity score

SSVC

Stakeholder-Specific Vulnerability Categorization: Act, Attend or Track

STIX

Structured Threat Information eXpression, for sharing threat data

ATT&CK

Adversarial Tactics, Techniques and Common Knowledge (MITRE)

CTID

Center for Threat-Informed Defense (MITRE)

C2

Command-and-Control, the servers attackers use to steer infected machines

VPN

Virtual Private Network
